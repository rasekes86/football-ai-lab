# Consultar el motor desde ChatGPT

Abre un Issue público en el repositorio con título exacto: `[ANALISIS] Athletic Club vs Espanyol | 2026-11-20`. GitHub Actions atenderá exclusivamente peticiones del propietario, verificará los equipos en ESPN y comentará probabilidades calculadas (no apuestas). ChatGPT con GitHub conectado puede crear y leer el Issue.

No analiza encuentros pasados, no consulta apuestas en directo, no recomienda apostar, no ejecuta apuestas ni acepta más de 30 días hacia el futuro. Los Issues son **públicos**: no incluyas datos privados.
