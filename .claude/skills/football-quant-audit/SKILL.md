# Football Quant Audit
Esta skill adapta la metodología de claude-quant (MIT), y usa el estudio
de predicción y mercados deportivos incluido en references/prediction-sports-markets.md.
1. Lee el README del proyecto y el código exacto antes de afirmar que algo está integrado.
2. Diferencia pronósticos registrados antes del partido de backtests retrospectivos.
3. Audita walk-forward por fechas, normalización, nombres y cobertura de equipos.
4. Revisa la comparación contra referencias adecuadas; no prometas ganancia financiera.
5. Para cuotas, elimina el margen correctamente por casa y anota la hora de captura.
6. No uses apuestas con dinero real ni automatices colocación de apuestas.
